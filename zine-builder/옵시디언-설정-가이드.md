# Obsidian → 웹사이트 Zine 자동 발행 설정 가이드

이 문서를 따라 한 번만 설정해두면, 그 다음부터는 **Obsidian에서 노트를 쓰고 저장하기만 하면**
`chaery-yoon.de/zine.html`에 자동으로 올라갑니다. 터미널 명령어를 직접 실행할 필요는 없습니다.

---

## 0. 준비물

- 이 저장소(`website`)가 컴퓨터에 이미 클론되어 있어야 합니다.
  지금 이 폴더가 그 저장소입니다: `zine-builder/zine-source/` 안에 글을 쓰게 됩니다.
- [Obsidian](https://obsidian.md) 설치
- Git이 이 컴퓨터에 설치되어 있고, GitHub에 push할 수 있는 상태(로그인/인증)여야 합니다.
  (지금 이 폴더에서 이미 `git`으로 커밋/푸시를 해본 적이 있다면 이미 준비된 것입니다.)

## 1. Obsidian vault를 `zine-source` 폴더에 연결하기

두 가지 방법 중 편한 쪽을 고르세요.

### 방법 A — `zine-source` 폴더를 새 vault로 바로 열기 (가장 간단, 추천)

1. Obsidian 실행 → 왼쪽 아래 vault 목록 아이콘 클릭 → **"Open folder as vault"**
2. 아래 경로를 선택:
   ```
   c:\Users\chery\Desktop\ChaeryYoon_Website\zine-builder\zine-source
   ```
3. 이제 이 폴더가 그대로 Obsidian vault가 됩니다. 여기에 쓰는 모든 `.md` 노트가
   빌드 대상이 됩니다 (단, `publish: true`가 붙은 것만 — 아래 3번 참고).

### 방법 B — 기존에 쓰던 vault에서 심볼릭 링크로 연결하기

이미 쓰고 있는 다른 vault 안에서 계속 작업하고 싶다면, 그 vault 폴더 안에 이 폴더로
연결되는 "바로가기(심볼릭 링크)"를 만들 수 있습니다.

PowerShell을 **관리자 권한으로** 열고 아래 명령어를 실행하세요 (`기존vault경로`는 실제 경로로 교체):

```powershell
New-Item -ItemType SymbolicLink `
  -Path "기존vault경로\Zine" `
  -Target "c:\Users\chery\Desktop\ChaeryYoon_Website\zine-builder\zine-source"
```

그러면 기존 vault 안에 "Zine"이라는 폴더가 생기고, 그 안에 글을 쓰면 실제로는
`zine-source` 폴더에 저장됩니다. 방법 A가 더 간단하니, 특별한 이유가 없다면 A를 추천합니다.

## 2. "Obsidian Git" 플러그인 설치 — 저장하면 자동으로 GitHub에 올라가게 하기

1. Obsidian 좌측 하단 **설정(톱니바퀴)** → **Community plugins**
2. "Restricted mode"가 켜져 있다면 꺼주세요 (Turn on community plugins)
3. **Browse** 클릭 → 검색창에 `Git` 입력 → **Obsidian Git** (제작자: Vinzent03) 설치 → **Enable**
4. 설치된 "Git" 플러그인의 설정으로 들어가서 아래 항목을 설정합니다:
   - **Vault backup interval (minutes)**: 예를 들어 `2`로 설정하면 2분마다 변경사항을
     자동으로 commit + push 합니다.
   - **Commit message**: 기본값 그대로 두어도 됩니다 (예: `vault backup: {{date}}`)
   - **Auto pull on boot / interval**: 켜두면 다른 기기에서 쓴 글도 자동으로 받아옵니다.

이렇게 해두면 노트를 쓰고 저장한 뒤 설정한 시간(예: 2분)이 지나면 자동으로
GitHub에 push되고, 곧이어 웹사이트 빌드가 시작됩니다.

> 더 즉각적으로 올리고 싶다면, `Ctrl+P`(명령 팔레트) → `Git: Commit and Sync` 를
> 실행하면 바로 커밋 + 푸시됩니다. 이 명령에 단축키를 지정해두면 편합니다
> (설정 → Hotkeys → "Git: Commit and Sync" 검색 후 원하는 키 지정).

> **최초 1회**는 Git이 GitHub 로그인 정보를 물어볼 수 있습니다. 이 컴퓨터에서 이미
> 이 저장소를 push해본 적이 있다면 별도 로그인 없이 바로 작동합니다.

## 3. 글쓰기 규칙 — Frontmatter (노트 맨 위에 넣는 정보)

새 노트를 만들 때 맨 위에 아래 형식을 꼭 넣어주세요:

```markdown
---
title: "글 제목"
date: 2026-08-07
excerpt: "목록에 보여줄 짧은 한 줄 소개 (생략 가능)"
publish: true
---

여기부터 본문을 마크다운으로 자유롭게 씁니다.
```

- **`publish: true`** — 이게 있어야만 사이트에 올라갑니다. `false`로 두거나 아예 이
  줄을 빼면 비공개 초안으로 남고, 절대 사이트에 노출되지 않습니다. 같은 폴더 안에
  초안을 마음껏 남겨둬도 안전합니다.
- **`title`** — 필수. 없으면 그 글은 빌드 시 건너뜁니다.
- **`date`** — `YYYY-MM-DD` 형식. 목록에서 최신순 정렬에 사용됩니다.
- **`excerpt`** — 생략하면 본문 앞부분에서 자동으로 요약해서 씁니다.
- 파일 이름이 곧 주소(URL)가 됩니다. 예를 들어 `첫 번째 글.md` → `zine/첫-번째-글.html`.
  직접 주소를 지정하고 싶으면 frontmatter에 `slug: my-first-post` 를 추가하세요.

### 알아두면 좋은 점: 이미지 첨부

지금 빌드 스크립트는 텍스트(마크다운)만 처리합니다. Obsidian에 이미지를 붙여넣을 때
기본값인 `![[이미지.png]]` 형식은 자동으로 인식되지 않습니다. 이미지를 넣고 싶다면:

- 이미지를 어딘가(예: 본인 웹호스팅, imgur 등)에 올리고 일반 마크다운 문법으로 넣기:
  `![설명](https://이미지주소.jpg)`
- 또는 Obsidian 설정 → **Files & Links** → **"Use [[Wikilinks]]"** 를 꺼두면
  Obsidian이 일반 마크다운 이미지 문법으로 저장해줍니다 (단, 이미지 파일 자체를
  저장소에 커밋하고 build-zine.js가 복사하도록 만드는 작업은 아직 안 되어 있으니,
  필요해지면 별도로 요청해서 추가하면 됩니다).

## 4. 빌드가 잘 됐는지 확인하는 법

1. GitHub에서 저장소 페이지로 이동: `https://github.com/yourfavgalcherry/website`
2. 상단 메뉴에서 **Actions** 탭 클릭
3. 맨 위에 있는 **"Build Zine"** workflow 실행 항목을 확인합니다:
   - 🟢 초록 체크 = 성공, 사이트에 반영됨
   - 🔴 빨간 x = 실패 — 클릭해서 로그를 열어보면 어떤 노트에서 문제가 있었는지
     (예: `title`이 빠졌다거나 frontmatter 형식이 잘못됐다거나) 나옵니다
   - 🟡 노란 점 = 아직 실행 중

4. 성공하면 보통 1~2분 안에 `https://chaery-yoon.de/zine.html`에서 확인할 수 있습니다.
   (GitHub Pages 자체 배포에도 약간의 시간이 걸릴 수 있습니다.)

> Actions 탭에 아무 실행 기록도 안 보인다면, `zine-source` 폴더 안의 글이 실제로
> GitHub에 push됐는지 확인해보세요 (Obsidian Git 플러그인이 아직 커밋을 안 했을 수
> 있습니다 — 2번 항목에서 설정한 backup interval을 기다리거나, 수동으로
> `Git: Commit and Sync` 명령을 실행해보세요).

## 전체 흐름 요약

```
Obsidian에서 노트 저장
   ↓ (Obsidian Git 플러그인이 자동 commit + push)
GitHub 저장소의 zine-builder/zine-source/ 변경됨
   ↓ (GitHub Actions "Build Zine" workflow 자동 실행)
publish: true 인 글만 HTML로 변환되어
zine.html / zine/글이름.html 생성 후 자동 커밋
   ↓ (GitHub Pages가 자동으로 사이트 재배포)
https://chaery-yoon.de/zine.html 에 반영 완료
```

사람이 직접 할 일은 **Obsidian에서 글 쓰고 저장하는 것**뿐입니다.

# Obsidian → Works 페이지 자동 발행 가이드

이 폴더(`zine-builder`)는 이제 웹사이트의 **Works 페이지**를 관리합니다. Obsidian에서
프로젝트 폴더를 만들고 저장하면, 자동으로 `chaery-yoon.de/works.html`의 그리드와
개별 프로젝트 페이지에 반영됩니다. 터미널 명령어를 직접 실행할 필요는 없습니다.

이미 Obsidian vault 연결과 "Obsidian Git" 플러그인 설치는 끝난 상태입니다
(`zine-builder/zine-source` 폴더를 vault로 열어두셨죠). 아래는 새 프로젝트를
추가하는 방법과, 알아두면 좋은 주의사항입니다.

---

## 1. 새 작업(Work) 추가하는 법 — "폴더 하나 = 작업 하나"

`zine-source` 안에 **새 폴더를 하나** 만드세요. 폴더 이름 맨 앞에 **번호를 붙이면
그 번호 순서대로 그리드에 나타납니다** (예: `01.KW_Kyiv_Biennial`, `02.Buttechno_kuboraum`).
번호가 작을수록 먼저 나옵니다. 순서를 나중에 바꾸고 싶으면 폴더 이름 앞의 숫자만
바꿔주면 됩니다 — `index.md` 안의 내용은 건드릴 필요 없어요.

그 폴더 안에:
1. **`index.md`** — 아래 2번 형식대로 글을 씁니다.
2. **이미지 파일들** — 슬라이더에 넣을 사진/gif를 같은 폴더에 넣습니다.
3. **커버 이미지** — Works 그리드에 썸네일로 쓸 이미지 1장 (다른 슬라이드 이미지와
   같은 파일이어도 되고, 별도 파일이어도 됩니다).

Obsidian에서 이미지를 붙여넣거나 드래그하면 자동으로 같은 폴더에 저장되도록
설정해두는 게 편합니다: 설정 → **Files & Links** → **Default location for new
attachments** → **"Same folder as current file"** 로 설정하세요.

> 폴더 구조 예시:
> ```
> zine-source/
>   13.MUTEK_2026/
>     index.md
>     cover.jpg
>     1.jpg
>     2.jpg
>     3.gif
> ```

> ⚠️ **자주 하는 실수**: Obsidian에서 `Ctrl+N`으로 새 노트를 만들면 기본적으로
> **폴더 없이 낱개 파일**(`제목.md`)로 생성됩니다. 이 상태로 저장하면 사이트에
> **절대 반영되지 않습니다** — 반드시 폴더를 먼저 만들고, 그 폴더 안에서
> 노트를 `index.md`라는 이름으로 저장하거나, 노트를 만든 뒤 폴더 안으로
> 옮겨주세요. (낱개로 남아있으면 다음 빌드 때 Actions 로그에 경고가 뜨니
> 4번에서 확인할 수 있습니다.)
>
> 폴더 이름에 띄어쓰기가 있어도 괜찮습니다 — 실제 웹 주소로 바뀔 때
> 자동으로 언더스코어(`_`)로 정리됩니다.

## 2. `index.md` 작성 형식 (Frontmatter)

```markdown
---
title: "그리드에 보여줄 제목"
projectTitle: "프로젝트 상세 페이지 제목 (예: 카테고리 | 프로젝트명)"
meta: "Berlin, 2026"
cover: cover.jpg
images:
  - 1.jpg
  - 2.jpg
  - 3.gif
publish: true
---

여기부터 프로젝트 설명을 마크다운으로 씁니다. *기울임*은 별표 두 개 대신 하나,
링크는 [이렇게](https://example.com) 씁니다.
```

각 항목 설명:

- **`title`** — Works 그리드 카드에 보이는 제목. 필수.
- **`projectTitle`** — 상세 페이지 상단 제목. 생략하면 `title`과 같은 값을 씁니다.
- **`meta`** — 상세 페이지의 날짜/장소 줄. `"Berlin, 2025 | [Event Link](주소)"`처럼
  링크를 하나 넣을 수도 있습니다.
- **`cover`** — 그리드 썸네일로 쓸 이미지 파일명 (같은 폴더 안에 있어야 함). 필수.
- **`images`** — 상세 페이지 슬라이더에 순서대로 들어갈 이미지 파일명 목록. 필수,
  최소 1개 이상.
  - 접근성을 위해 설명(alt text)을 넣고 싶으면:
    ```yaml
    images:
      - src: 1.jpg
        alt: "무대 전경"
      - 2.gif
    ```
- **`publish`** — **`true`**여야만 사이트에 올라갑니다. `false`로 두거나 이 줄을
  빼면 비공개 초안으로 남습니다. 작업 중인 프로젝트는 안심하고 `publish: false`로
  같은 폴더에 두세요.
- **`slug`** — (선택) 페이지 주소를 직접 고정하고 싶을 때 씁니다. 안 적으면
  폴더 이름(맨 앞 번호 제외)에서 자동으로 만듭니다. **한 번 발행된 작업은
  나중에 폴더 이름을 바꾸더라도 주소가 안 바뀌도록, 이미 있는 12개 작업에는
  전부 `slug`를 명시적으로 넣어뒀습니다.** 새로 만드는 작업은 굳이 안 넣어도
  되지만, 나중에 폴더 이름을 바꿀 계획이 있다면 처음부터 넣어두는 게 안전합니다.

> 순서는 이제 **폴더 이름 앞 번호**로 정합니다 (위 1번 참고). `order` 필드는
> 더 이상 넣지 않아도 되지만, 완전히 없어진 기능은 아니에요 — frontmatter에
> `order:`를 넣으면 폴더 번호보다 그게 우선합니다. 웬만하면 폴더 번호 하나로만
> 관리하시는 걸 추천해요 (두 가지를 같이 쓰면 헷갈릴 수 있어요).

**필수 항목(`title`, `cover`, `images`)이 없거나, `cover`/`images`에 적은 파일이
실제로 폴더 안에 없으면 그 작업은 조용히 건너뜁니다** (사이트가 깨지지 않도록).
Actions 탭 로그에서 어떤 파일이 왜 빠졌는지 확인할 수 있습니다 (4번 참고).

## 3. 기존 작업 수정하기

기존 프로젝트 폴더(`02.Buttechno_kuboraum`, `06.Luna`, `07.Thesis` 등)를 열어서
`index.md`의 텍스트나 `images` 목록을 수정하고 저장하면, 다음 빌드 때 자동으로
반영됩니다. 이미지를 바꾸고 싶으면 같은 파일명으로 덮어쓰거나, `index.md`의
`images`/`cover` 목록을 새 파일명으로 바꿔주면 됩니다.

순서를 바꾸고 싶으면 폴더 이름 맨 앞 숫자만 바꾸세요 (예: `06.Luna` →
`03.Luna`, 다른 폴더 번호는 자동으로 다시 정렬할 필요 없이 그 사이 아무
숫자로만 넣어도 순서가 맞춰집니다). 이미 있는 12개 작업은 전부 `slug`가
고정돼 있어서, 순서를 바꿔도 주소(URL)는 그대로 유지됩니다.

작업을 그리드에서 내리고 싶을 땐 `index.md`에서 `publish: false`로 바꾸면 됩니다
(폴더 자체를 지울 필요 없음). 다음 빌드 때 해당 프로젝트 페이지와 그리드 카드가
자동으로 사라집니다.

## 4. 빌드가 잘 됐는지 확인하는 법

1. GitHub 저장소 페이지로 이동: `https://github.com/yourfavgalcherry/website`
2. 상단 메뉴에서 **Actions** 탭 클릭
3. 맨 위 **"Build Works"** workflow 실행 항목을 확인합니다:
   - 🟢 초록 체크 = 성공, 사이트에 반영됨
   - 🔴 빨간 x = 실패 — 클릭해서 로그 확인 (예: `cover` 파일명 오타 등)
   - 🟡 노란 점 = 진행 중
4. 성공하면 보통 1~2분 안에 `https://chaery-yoon.de/works.html`에서 확인할 수
   있습니다.

**"분명히 추가했는데 사이트에 안 보여요"** 싶을 땐, Actions 로그를 열어서
`[works] IGNORING "..."` 또는 `[works] skipping "..."`로 시작하는 줄이 있는지
확인하세요. 대부분 아래 둘 중 하나입니다:
- 노트가 폴더 없이 낱개 파일로 저장됨 (위 "자주 하는 실수" 참고)
- `title`/`cover`/`images` 중 하나가 빠졌거나, `cover`/`images`에 적은
  파일명이 실제 폴더 안 파일명과 다름 (대소문자도 정확히 일치해야 함)

## 참고: 이 폴더가 "zine-builder"라고 불리는 이유

폴더 이름은 `zine-builder`/`zine-source`로 남아있지만, 지금은 Works 페이지를
관리하는 용도로 쓰입니다. 이미 Obsidian vault가 이 폴더를 가리키도록 연결되어
있어서, 이름을 바꾸면 vault 연결이 깨지기 때문에 이름은 그대로 두었습니다.
실제 동작(빌드 결과)에는 영향이 없으니 신경 쓰지 않으셔도 됩니다.

## 전체 흐름 요약

```
Obsidian에서 프로젝트 폴더 + index.md 저장
   ↓ (Obsidian Git 플러그인이 자동 commit + push)
GitHub 저장소의 zine-builder/zine-source/ 변경됨
   ↓ (GitHub Actions "Build Works" workflow 자동 실행)
publish: true 인 작업만 works.html 그리드 카드 +
works/projects/폴더명/폴더명.html 페이지로 생성되어 자동 커밋
   ↓ (GitHub Pages가 자동으로 사이트 재배포)
https://chaery-yoon.de/works.html 에 반영 완료
```

사람이 직접 할 일은 **Obsidian에서 폴더 만들고 글/이미지 저장하는 것**뿐입니다.
